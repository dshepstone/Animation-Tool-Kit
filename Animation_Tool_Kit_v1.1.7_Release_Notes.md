# Animation Tool Kit v1.1.7

Adds **Overlap 0.4.0** to the animation/timing tools, next to Noise Generator.

- Add spring overlap to existing control animation, including ordered FK chains.
- Choose local X/Y/Z output channels, including Rotate X only.
- Preserve offset pivots and preview the result before baking.
- Bake to a separate animation layer, with optional key reduction and tolerance.
- Delete a selected bake and recreate the pass while retaining source animation.
- Read the offline HTML guide, examples, suggested numbers, and licence from Help.
- Use the custom 32x32 pendulum icon, with a generated fallback if an icon is missing.

The package, help, icon, and separate licence are included in the ATK installer
and distribution. A standalone Overlap installation is not needed.

## Installation

Extract the package and drag `install_atk_toolbar.mel` into Maya. If updating an
already open toolbar, close/reopen ATK or use its Reload Scripts command.
Overlap can be hidden/shown through the existing tool visibility settings.
