Animation Tweaker

User guide · Version 1.0.0 · Offline reference

Sculpt shot-specific corrections onto animated characters after the skin, then key them on and off. Every correction is stored as a target on one blendShape per mesh, so nothing else is added to your scene.

Quick start · Keying modes · Effects · Surface Handle · Troubleshooting

Getting started

  1. Select the character mesh and click Use selected.
  2. Go to the frame you want to fix. Pick a keying mode on the Sculpt tab.
  3. Click Sculpt. A blue copy of the mesh, exactly as it looks on this frame, replaces the original in the viewport.
  4. Sculpt the copy with any Maya tool: sculpt brushes, soft selection, move vertices.
  5. Click Commit. The difference is stored as a tweak and keyed. The copy is deleted. Cancel throws the copy away and changes nothing.

Each button is a single Undo. A sculpt in progress is saved in the scene, so it survives Reload Scripts and reopening the window. File > Cancel every open sculpt clears any you forgot.

How tweaks are stored

The first tweak on a mesh creates a blendShape called <mesh>_atkTweaks, placed after the skinCluster and any other deformers. Each tweak is one target on it. The target holds the offsets in the mesh's object space; no target meshes are kept. Each weight gets a readable name such as tw_sculpt_L1_f24, and the tweak's label, kind, frame and level are saved as JSON on the node.

Turn on Proxy channels on mesh to get a keyable copy of every weight on the mesh transform, under a TWEAKS divider in the Channel Box. Existing keys move onto the proxies. Turning it off moves them back.

Deleting <mesh>_atkTweaks removes Animation Tweaker from a mesh completely.

Sculpt and commit

Highlight shader / Hide original

The sculpt copy gets a light blue material so it is easy to tell apart, and the original is hidden while you work. Both are restored on Commit or Cancel.

Sculpt from zero

Mutes some existing tweaks while you sculpt, so the new tweak is measured against the mesh without them:

ChoiceMuted while sculpting
OffNothing. You sculpt on top of everything.
Mute all tweaksEvery tweak on the mesh.
Mute static and pulse tweaksStatic and pulse tweaks only.
Mute sequence tweaksAll pose-to-pose tweaks on every level.
Mute this level onlyPose-to-pose tweaks on the level in the Level box.

Muted tweaks come back on Commit or Cancel, with their keys intact.

Refine

Select one tweak in the list and click Refine. Sculpt a correction; on Commit it is added to that tweak. If the tweak is half on (weight 0.5) on this frame, the correction is scaled so the result looks exactly like your sculpt. Refine needs the tweak's weight to be above 0 on the current frame.

Keying modes

ModeKeysUse it for
StaticNo keys, weight 1.A fix that should always show, such as a model correction.
Pulse0 at frame − ramp in, 1 on the frame, 0 at frame + ramp out. A one-off fix: an intersection on a contact frame, a smear.
Sequence1 on its own frame, 0 on the frames of the poses either side of it on the same level. Pose-to-pose shape animation: each sculpt crossfades into the next.

Sequence tweaks live on levels (L1, L2, ...). Each level is an independent pose-to-pose track, so you can run a cheek track and a cloth track without them affecting each other. Adding or deleting a pose rekeys its whole level. Sculpting on a frame that already has a pose on that level adds to that pose. A new pose between two others starts from the in-between shape the level shows on that frame, so what you sculpted is exactly what you get after Commit (unless you muted that level while sculpting).

The first pose of a level stays on before its frame and the last stays on after it. To end a track, add a Blank pose: an empty pose that the previous one fades into.

Hold pose copies the previous pose on the level to the current frame, so the shape holds and then moves on.

Tweak list

Lists every tweak on the mesh with its kind, mode, frame and level. Drag a weight slider to try a value and click Key to key it on the current frame (Key* means the weight is already animated).

  • Amplify × scales the selected tweaks' offsets: 1.25 is 25% stronger, 0.5 half, −1 flips them.
  • Rename changes the label and the weight's name.
  • Paint mask opens Maya's Paint Blend Shape Weights tool on that tweak, so you can paint where it applies.
  • Delete removes the target, its keys and its proxy channel, and rekeys its level.

Shape: inflate and relax

Both work on the mesh as it is on the current frame and are stored as tweaks with the Sculpt tab's keying mode. Select vertices to limit them; with soft selection on, the falloff becomes the strength.

Inflate / Deflate moves vertices along their normals by Distance. Relax smooths the surface: each iteration moves every vertex part of the way (Strength) toward the average of its neighbours. Unselected vertices stay put, so the relaxed area blends into the rest.

Effects

Effects work over a frame range and bake one pose per frame on their own level (fx_smooth_motion, fx_stick, fx_push_out, fx_pin). Neighbouring frames crossfade and the effect fades out one frame outside the range. Running an effect again replaces its earlier result. The selected vertices, with soft selection, are the mask.

EffectWhat it does
Smooth MotionAverages each vertex's path over time with a Gaussian filter. Smoothing is the filter width in frames; larger values remove more jitter. World space smooths the path in the scene; turn it off to smooth only the deformation relative to the mesh's transform.
Stick to SurfaceOn the bind frame, records where each vertex sits relative to the closest point on the driver mesh, then keeps it there on every frame. Good for a hand resting on a thigh, or a strap on a shoulder.
Push OutWherever a vertex is inside the driver mesh (or closer than Skin offset), it is pushed out along the driver's surface normal. The driver's normals must point outward.
Pin to WorldHolds the masked vertices exactly where they were in the world on the bind frame.

Surface Handle

Select one vertex and click Create on selected vertex. You get a soft-modification handle that rides the skin: it follows the mesh as it animates, and moving or keying the handle pushes the surface around it.

The handle needs UVs to ride the surface. On a mesh without UVs it is placed at the vertex and stays there, with a warning.

On the handle in the Channel Box: falloffRadius, falloffMode (Volume or Surface), falloffShape, envelope, showFalloff and orientToWorld. Pick a falloff shape in the window and click Apply to rebuild the falloff curve. Aim at selected points the handle's axes at another object; Clear aim removes it. Add / Remove geometry lets one handle deform several meshes.

Utilities

  • Locator / Card on vertex: bakes a locator (position) or a small card (position and orientation) onto each selected vertex over the playback range. Use them as constraint targets or reference.
  • Bake mesh transforms: bakes the selected objects' translate, rotate and scale to a key on every frame and removes their constraints.
  • Smooth preview: toggles smooth-mesh preview on every mesh under the selection.
  • Next camera: the active viewport looks through the next camera in the scene. Ortho cameras are skipped unless you untick the box.
  • Colour materials: click a swatch to give the selected meshes or faces a flat colour; ? picks a random one. Materials are shared by colour (atkColour_rrggbb).
  • Copy / Paste values: copies the keyable channel values of the selection (or the channels highlighted in the Channel Box) and pastes them onto other objects. With one source, every target gets its values; with several, objects are matched by name, then by order. With Auto Key on, pasted channels are keyed. The values are kept in Maya's preferences as plain data.
  • Extract faces (live copy): makes a separate mesh from the selected faces that keeps following the original, including skinning and tweaks.

Cache versions

  1. Export selected… writes the selected meshes to an Alembic file. Each mesh is tagged with its own path so the cache can find it again.
  2. Import version… brings a cache back as a version under ATK_TweakCache_CTL.
  3. Attach drives the original meshes from the chosen (or active) version. The control's envelope fades the cache in and out and can be keyed.
  4. Swap to selected switches the attached meshes to another version. Only the active version is shown.
  5. Detach removes the attach blendShapes; Delete version removes a version.

The Alembic plug-ins (AbcExport, AbcImport) are loaded when needed.

Troubleshooting

  • "The sculpt has N vertices but the mesh has M": the copy's topology was changed (faces added or deleted). Cancel and sculpt again without changing topology.
  • A tweak moves the wrong way after the character turns: tweaks are stored in the mesh's object space after the skin, so they turn with the transform but not with joints. Use a Sequence tweak per pose, or a Surface Handle.
  • Nothing happens when sculpting a sequence pose: check the level name. Poses on different levels do not crossfade.
  • Paint mask opens but paints the wrong target: pick the tweak's name in the paint tool's target list.
  • Surface Handle does not follow the skin: the mesh has no UVs, or the UVs overlap at that vertex.
