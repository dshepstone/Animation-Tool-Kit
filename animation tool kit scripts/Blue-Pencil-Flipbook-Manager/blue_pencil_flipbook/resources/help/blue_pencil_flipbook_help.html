How to Use the Flipbook Manager

Launch the tool, pick the active Camera and Blue Pencil Layer in the header, then mark drawing frames as Key, Breakdown, or Inbetween. Tracked drawings appear as thumbnail cards; clicking a card opens a larger review window (with a Go To Frame button that jumps Maya's current time to that drawing), and right-clicking a card offers per-frame actions. The Delete Frame action also removes the frame's tracked thumbnail from the strip.

The Camera field follows the viewport you are working in: it is set to the focused viewport's camera when the tool opens or refreshes, and it re-syncs to that camera each time you mark a frame, so the drawing and its thumbnail are always tagged with and captured from the correct camera. You can still pick a camera manually to review another camera's drawings. Blue Pencil layers are read per-camera through Maya's bluePencilLayer command, so changing the camera reloads its layers automatically.

Marking a frame captures a viewport thumbnail of that drawing the first time it is marked. In normal mode the capture uses the visible model panel first so it matches a regular playblast/viewport view, with off-screen capture methods as fallbacks. If you keep drawing on that frame, click the ↻ update button on the card to re-capture it, or use the card's right-click Regenerate Thumbnail / View > Regenerate All Thumbnails. The default stroke color is a light Blue Pencil blue; change it with the Color swatch.

Isolate on white (next to the Mark buttons) controls how the thumbnail is saved. When checked, the scene geometry and rig are hidden for the capture and the image's background is keyed to pure white, so only the Blue Pencil drawing shows on the card. When unchecked, the geometry and rig are forced visible so the thumbnail shows the model and controls behind the drawing. Your Maya viewport is restored to its own display settings afterward either way.

Drawing Tools

The drawing row wraps the Maya bluePencilUtil commands: Draw, Transform, Pencil, Brush, Eraser, Text, Line, Arrow, Ellipse, and Rectangle. The active tool stays highlighted. Use the Color swatch to set the stroke color (sent to Maya as 0–255 RGB), and the Size and Opacity sliders to adjust the active tool. Reset Tool restores Blue Pencil defaults.

Frame Types

  • KEY Key drawing — primary storytelling pose.
  • BDN Breakdown drawing — transitional pose.
  • INB Inbetween drawing — smoothing frame.

Frame types are stored as tool metadata on a hidden network node in the scene, so they travel with the file.

Export & Import Sessions

Use File > Export Session… (or the Export Frames button) to save the current session to a self-contained folder named BluePencilFlipbook_Session_<timestamp>. It contains:

  • session.json — the tracked-frame metadata (types, cameras, layers).
  • thumbnails/ — the captured thumbnail images.
  • blue_pencil.zip — the actual Blue Pencil drawing archive (strokes per frame/camera), written with Maya's bluePencilFrame -exportArchive.

Use File > Import Session… (or the Import Frames button) and pick a previously exported session folder. The Blue Pencil drawings are restored from the archive with -importArchive (re-creating the frames on their camera), the thumbnails are copied back into the tool's cache, and the metadata is loaded. Choose Replace to swap in the imported set or Merge to add to the current tracked drawings. The Export/Import Session menu items and the Export/Import Frames buttons run the same operation.

Playback Filters

Filtered playback uses a Qt timer and sets Maya's current time only on tracked frames. Choose Keys Only, Keys + Breakdowns, or All Drawings, set the FPS, and toggle Loop. The transport buttons step to the previous/next tracked drawing, play/pause, and stop.

Hotkeys

Use Hotkeys > Edit Hotkeys… to open the editor, where you can set the Ctrl/Alt/Shift modifiers and key for each action and click Apply to bind and save them (they persist and reload). Restore Defaults refills the defaults and Remove All unbinds them. The Hotkeys menu also has quick Create/Reset/Remove items. Defaults: Ctrl+Alt+B toggles the manager, Alt+R resets the tool, Alt+, and Alt+. step drawings, Alt+1/2/3 play filters, and Ctrl+1/2/3 mark frame types.

About

Blue Pencil Flipbook Manager is a dockable Maya 2026 PySide2/PySide6 utility for improving Blue Pencil review workflows, styled to match the Animation Tool Kit.
