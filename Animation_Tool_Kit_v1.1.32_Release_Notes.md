# Animation Tool Kit 1.1.32 — Smart Select Sets pop-out close button

Smart Select Sets is now version 2.6.1.

## Fixed: the x button did not close a pop-out

In Maya, clicking the **x** in the corner of a Smart Select Sets pop-out left
the pop-out open. The button now closes the pop-out as soon as it is pressed,
and a pop-out that Maya refuses to close is hidden and removed anyway. Esc
closes a pop-out the same way.

## Retained features

Includes everything from 1.1.31: pop-outs that stay open after the main window
is closed and stay in front of Maya without covering other applications,
dragging buttons into a new position, reusing a deleted category name, the
working category Rename button, the TweenMachine fix from 1.1.30, and all
earlier tools and fixes.
